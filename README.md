# Monitoramento de Servidores SQL

Projeto desenvolvido para praticar SQL, modelagem de banco de dados e consultas relacionais.

## Estrutura do Projeto

### Tabelas

* users
* detalhes

### Recursos Utilizados

* CREATE TABLE
* PRIMARY KEY
* FOREIGN KEY
* ALTER TABLE
* INSERT INTO
* INNER JOIN
* EXISTS
* WHERE
* ORDER BY

## Arquivos

* schema.sql → Estrutura do banco de dados
* inserts.sql → Dados de exemplo
* queries.sql → Consultas SQL desenvolvidas

## Objetivo

Praticar conceitos fundamentais de banco de dados relacionais e consultas SQL aplicadas a um cenário de monitoramento de servidores.
